# Require x86-64-v3

Ploof version one will require the x86-64-v3 ISA, making AVX2 and BMI2-class
instructions available to every supported deployment. Explicit Zig vector
code may select wider lanes at compile time when the build target includes
AVX-512, but every specialization must beat the scalar oracle in differential
tests and justify itself in benchmarks. AVX-512 is an optimization, not a
deployment requirement.

Version one will specialize only for the build target. Portable builds target
x86-64-v3; deployment builds may target a specific CPU. Ploof will not ship a
fat binary or perform runtime CPU-feature dispatch initially.
